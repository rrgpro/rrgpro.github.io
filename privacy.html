Политика конфиденциальности

Приложение «Личный ассистент iShef Pro» используется только владельцем аккаунта Google, который сам выдал ему доступ.

  • Данные Google (письма, события, файлы, документы, контакты) используются только для выполнения команд владельца.
  • Данные не продаются, не передаются третьим лицам и не используются для рекламы.
  • Использование данных, полученных через API Google, соответствует Политике Google в отношении пользовательских данных API, включая требования ограниченного использования.
  • Доступ можно отозвать в любой момент: myaccount.google.com → «Безопасность» → «Сторонние приложения и сервисы».
